📖 使用教程
1. 环境依赖
Python 3.6 及以上版本（推荐 Python 3.8+）

无需额外安装第三方库（仅依赖 Python 内置模块：tkinter、os、json、re、datetime、sys）

2. 运行方式
方法一：直接运行源码

bash
python editor.py
方法二：打包为独立 exe（Windows）
安装 PyInstaller：

bash
pip install pyinstaller
执行打包命令（替换 myicon.ico 为你的图标文件）：

bash
pyinstaller --onefile --windowed --icon=myicon.ico --name=MyEditor editor.py
打包完成后，dist/MyEditor.exe 即可双击运行，无需安装 Python。

3. 软件功能速览
文件树：左侧展示所选文件夹下所有 .js / .json 文件，点击即可编辑。

当前文件查找替换：支持高亮所有匹配项、单个替换、全部替换。

文件夹级查找替换：递归搜索整个文件夹，显示所有匹配的文件行，支持“替换选中”和“全部替换（文件夹）”。

历史记录自动保存：每次替换操作都会记录（文件路径、旧文本、新文本、时间），保存在程序同目录下的 history.json。

导入新版并审查：当获得新版文件后，可依据历史记录自动应用修改，对多处匹配会询问用户。

行号不同步滚动：编辑区与行号区域不同步滚动，密码的我试了好几遍都没弄好，不干了，tnnd不如吃几个血棒

4. 历史记录文件说明
文件路径：程序所在目录下的 history.json。

若文件不存在，程序首次启动会自动创建。

若文件损坏（如空文件），程序会自动修复。

可通过工具栏“📜 查看历史”按钮查看内存中的记录。
